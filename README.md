# userscripts

Tampermonkey / Violentmonkey userscripts by gridmannn.

Install [Tampermonkey](https://www.tampermonkey.net/), then click an **Install** link below. Installed scripts auto-update from this repo.

| Script | What it does | Install |
|---|---|---|
| Endless STL Pages | Endless-Google-style auto paging for Thingiverse, Printables, MakerWorld, Cults3D, MyMiniFactory and Thangs | [Install](https://raw.githubusercontent.com/gridmannn/userscripts/main/endless-stl-pages.user.js) |

## Notes

- Chromium-based browsers: enable **Allow User Scripts** for Tampermonkey in `chrome://extensions` → Details.
- Each script has a Tampermonkey menu toggle to turn it off.
